## 왜 기존 O-04/O-05 중심안이 바뀌었나

기존 O-04 `T-SHIRT + CAP`, O-05 `SWEATSHIRT + CAP`은 서로 다른 제품 조합이라 와디즈 특별구성 후보가 될 수 있었다. 그러나 두 조합은 한 Scene 전체도 아니고 같은 제품의 DAY/NIGHT Pair도 아니라, 왜 이 두 제품을 묶었는지 별도 설명이 필요했다.

또한 CAP 실물재고가 0이라는 사용자 확인이 들어왔다. CAP을 모든 핵심 구성에 넣으면 서울 시그니처가 아니라 생산 병목이 캠페인을 지배한다. 따라서 O-04/O-05는 삭제하지 않고 과거 후보로 보존하되 중심에서 내린다.

### THE DAY OF SEOUL — SET

DAY라는 한 장면을 세 제품으로 완성한다. 캠페인을 가장 정확히 보여주는 `Brand Hero(브랜드 대표 구성)` 후보다. 다만 가격과 CAP 생산 때문에 최다 판매 구성이 아닐 수 있다.

### THE NIGHT OF SEOUL — SET

DAY와 동일한 위계다. DAY/NIGHT 수요 우열을 추측하지 않는다.

## ONE SEOUL 판매계열

### ONE SEOUL — T-SHIRT SET

DAY + NIGHT T-SHIRT. 두 장면을 가장 낮은 부담으로 함께 소유하는 `Core(핵심 구매 구성)` 후보다.

### ONE SEOUL — SWEATSHIRT SET

DAY + NIGHT SWEATSHIRT. 패션·공정·장면이 강하지만 가격 장벽이 있어 조건부 `Upper Core(상위 핵심 구성)`다.

### ONE SEOUL — CAP SET

명명 논리는 정확하지만 CAP 두 개의 중복 체감과 양쪽 생산 의존 때문에 초기 화면에서는 보류한다.

### ONE SEOUL — FULL SET

DAY/NIGHT 6제품 전체. 판매량보다 컬렉션의 최대 범위와 상위 기준점을 보여주는 `Premium Anchor(상위 기준 구성)`다. 가격·옵션·CAP 생산·발송을 모두 잠글 수 있을 때만 실제 노출한다.
