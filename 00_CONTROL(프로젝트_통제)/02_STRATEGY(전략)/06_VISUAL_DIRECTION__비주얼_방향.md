## 03. 안전영역과 긴장영역

### 안전영역

- 실제 제품 픽셀, 실제 착용, 실제 서울 장면을 우선한다.
- 넓은 여백, 제한된 문장, 한 화면 한 메시지를 유지한다.
- 장면 뒤에는 반드시 식별 가능한 제품 또는 디테일 증거가 따라온다.
- 정보 모듈은 중립적이고 읽기 쉽게 만든다.

### 긴장영역

- DAY와 NIGHT에 서로 다른 화면 재질·속도·크롭을 허용하되 면적과 제품 위계는 동등하게 유지한다.
- 서울 마크를 크게 확대하거나 장면과 중첩할 수 있으나 승인 원형은 변형하지 않는다.
- 장면과 제품의 Match Cut, 비대칭 편집, 세로 여백을 사용할 수 있다.
- 기존 자산의 배경·빛·비율은 통합할 수 있지만 제품 그래픽·실루엣·봉제·핏은 만들거나 바꾸지 않는다.

## 06. 예상 시각 블록 밀도

첫 작업 범위는 `약 30~40개 Editorial Block + 별도 Commerce Utility`다. 이는 Quota나 최종 화면 수가 아니다. 한 Block 안에 Full Frame, Detail Crop, Front/Back, Scene/Product Pair, DAY/NIGHT Pair처럼 여러 실제 이미지가 들어갈 수 있으므로 전체 이미지 수는 50개를 넘을 수 있다.

20장 미만 상세페이지의 낮은 성과 관찰값, 50장 이상 이미지 활용, 상단 GIF 데이터를 참고하되 모두 심사 의무가 아니라 성과 관찰·권고다. 최종 수량보다 각 Block이 고객 질문을 실제로 해결하는지를 우선한다.

## 09. 타이포그래피 체계

폰트 자체는 Content Clearance 전 확정하지 않는다. `PRIMARY TYPE FAMILY 1개`를 House Foundation으로 사용하고, 필요한 경우 `SECONDARY TYPE FAMILY 최대 1개`만 검토한다. Secondary는 Condensed 또는 Mono 중 하나이며 둘 다 강하게 쓰지 않는다.

| 역할 | 작업 범주 | 사용 원칙 |
| --- | --- | --- |
| House Foundation | Primary Family 1개 | XXX STUDIO·KOREA TOUR·Chapter·Product·Utility를 같은 House로 묶음 |
| Project Emphasis | Primary의 Scale·Weight·Tracking·Alignment | KOREA TOUR와 Chapter를 별도 브랜드가 아니라 Project Layer로 구분 |
| Secondary Candidate | Condensed 또는 Mono 중 최대 1개 | Coordinate·Ticket·Metadata에 제한. Airport·Techwear·Tourism System 과잉 방지 |
| Product / Utility | Primary의 높은 판독 구간·Tabular Number | 소재·가공·가격·옵션·배송·정책의 빠른 비교 |

위계는 Typeface 수가 아니라 Scale, Weight, Tracking, Alignment, Grid, Whitespace로 만든다. `XXX STUDIO`와 `REPUBLIC OF KOREA TOUR`를 Collaboration Partner처럼 같은 무게로 병치하지 않는다. Font Source와 License는 최종 사용 전 별도 확인한다.
