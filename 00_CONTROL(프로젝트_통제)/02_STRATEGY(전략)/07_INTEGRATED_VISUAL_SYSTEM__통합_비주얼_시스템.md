이 문서는 하나의 Master Source (기준 원본)를 네 채널에 맞게 다르게 편집하기 위한 정본이다. 실제 Image (이미지)·GIF·Video (영상)·HTML·Website (웹사이트)·Post (게시물)·Ad (광고)·Package (패키지)를 만들거나 게시하지 않으며, Final Copy (최종 문구)·Price (가격)·Reward (리워드)·Quantity (수량)·Delivery (배송)·Content Clearance (콘텐츠 사용 승인)를 승인하지 않는다.

반복 용어는 Master Source (기준 원본), Channel-specific Edit (채널별 편집), Master Visual DNA (공통 비주얼 핵심 체계), Fixed / Flexible (고정 / 가변), Content Reuse Rule (콘텐츠 재사용 규칙)의 뜻으로 사용한다.
