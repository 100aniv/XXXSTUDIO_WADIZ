# TERMINOLOGY GLOSSARY (프로젝트 용어집)

상태: `ACTIVE / PROJECT-WIDE (프로젝트 전역 적용)`  
기준일: 2026-08-14

이 문서는 프로젝트 담당자가 영어 전문용어 때문에 의미를 놓치지 않도록 만든 용어집이다. 파일명, Task ID, 상태값, Asset ID, 브랜드·제품 고유명, URL, 고정 Slogan은 번역하거나 바꾸지 않는다.

## PROJECT LANGUAGE STANDARD (프로젝트 언어·용어 표준)

1. 전문 프로젝트·마케팅·크리에이티브 영어 용어는 유지한다.
2. 첫 의미 있는 등장과 중요 Heading(제목)·Table Label(표 항목명)에는 이해하기 쉬운 한국어 설명을 괄호로 병기한다.
3. 같은 Section(섹션) 안에서 이미 정의한 용어는 반복 병기하지 않는다.
4. `XXX STUDIO`, `EXPERIENCE`, `REPUBLIC OF KOREA TOUR`, `EXPERIENCE SCENE OF KOREA`, `SEOUL : DAY & NIGHT`, `THE DAY OF SEOUL`, `THE NIGHT OF SEOUL`, `ONE SEOUL`은 고유명으로 번역하지 않는다.
5. Task ID, Asset ID, Status Token(상태값), URL, SHA, 파일 확장자, 경로, Code(코드), Formula(수식), Technical Schema(기술 스키마)는 변경하지 않는다.
6. 신규 Human-readable File(사람이 읽는 파일)은 의존성 위험이 없을 때 `NN_ENGLISH_NAME__한글_설명.ext`를 사용한다.
7. 기존 Dependency-critical File / Folder(경로 의존 파일 / 폴더)는 Rename(이름 변경)하지 않고 내부 제목에서 설명한다.
8. 활성 Canonical Document(정본 문서)는 제자리에서 정상화하며 V2·FINAL·KOREAN 복제본을 만들지 않는다.
9. Historical Report(과거 보고서), Archive(보관 자료), Raw Source(원본 자료), Handoff ZIP(전달 압축파일), Audit Snapshot(감사 시점 기록)은 과거 증거 보존을 위해 일괄 수정하지 않는다.
10. WORK 최종 보고에도 같은 규칙을 적용하며 영어 Heading만 단독 사용하지 않는다.
11. QA(품질 검수)의 `BILINGUAL TERMINOLOGY COMPLIANCE (영문 용어 한글 병기 준수)`가 실패하면 완료 처리하지 않는다.

### WORK REPORTING TEMPLATE (작업 결과 보고 양식)

WORK 최종 보고는 작업 성격에 맞게 필요한 항목만 사용하되, 영어 제목을 쓸 때는 아래처럼 한국어 설명을 함께 쓴다.

1. `전체 판정`
2. `이번에 실제로 바뀐 것`
3. `Creative / Brand Review (크리에이티브 / 브랜드 검토)`
4. `Integrated Visual Matrix (통합 비주얼 매트릭스)`
5. `Business / Risk (사업성 / 리스크)`
6. `Project Status (프로젝트 진행 상태)`
7. `남은 결정사항`
8. `Next Action (다음 행동)`
9. `Handoff ZIP (전달 압축파일)`

프로젝트에 해당하지 않는 항목을 억지로 만들지는 않지만, 사용하는 제목의 영문·한국어 대응은 위 형식을 유지한다.

| 용어 | 프로젝트에서 쓰는 뜻 | 사용 원칙 |
| --- | --- | --- |
| Brand Core | 브랜드 핵심 철학 | XXX STUDIO에서는 `EXPERIENCE` |
| Project | 브랜드가 반복해서 전개하는 프로젝트 | `REPUBLIC OF KOREA TOUR` |
| Chapter | 프로젝트 안의 특정 장소·시기 단위 | `CHAPTER 01 — SEOUL : DAY & NIGHT` |
| Creative Thesis | 캠페인의 핵심을 날카롭게 설명하는 작업용 표현 | `TWO SCENES. ONE SEOUL.`은 현재 후보이며 최종 문구가 아님 |
| Campaign Territory | 캠페인 방향 또는 콘셉트 영역 | 현재 `SCENE PASSPORT`를 Master Territory로 쓰지 않음 |
| Design Logic | 실제 장면에서 디자인 요소를 가져와 제품에 구현한 논리 | `Translation`을 공식 방법론으로 만들지 않음 |
| Seoul Signature Mark | 서울 한글 시그니처 마크 | DAY/NIGHT 랜드마크 형상을 결합한 Chapter 전용 자산 |
| Chapter-specific Asset | 특정 Chapter에만 속하는 자산 | XXX STUDIO 전체 Corporate Identity로 일반화하지 않음 |
| Actual Scene | 실제 촬영된 장소 장면 | 이미지 권리와 장소 사실을 별도로 확인 |
| Coordinate | 좌표, 장소·디자인 정보 | Experience Device가 아니라 Location Evidence |
| Scene Graphic | 실제 장면을 사용한 제품·편집 그래픽 | 현행 문구·좌표·사진 권리를 검증 |
| Product Proof | 제품 증거 | 실제 전·후면, Detail, Fit, 현행 SKU·사양 근거 |
| Fashion-first | 패션 우선 | 첫 인상에서 옷·실루엣·착용·그래픽이 보이는 원칙 |
| Product-first | 제품 우선 | 제품이 첫 관심·실제 증거·구매 이유를 맡는 원칙 |
| Experience Device | 경험 확장 장치 | Invitation, Ticket, QR, Package. 제품을 대체하지 않음 |
| Creative Evidence Backbone | 크리에이티브 근거 구조 | 실제 자산을 전략 주장과 연결하는 체계 |
| Re-curation | 현재 기준 재구성 | 기존 Chapter를 숨기지 않고 2026 기준으로 정리하는 일 |
| WHY NOW | 왜 지금 이 캠페인을 다시 여는지 설명하는 근거 | Hero보다 뒤에서 재큐레이션 사실과 현재 차이를 설명 |
| Supporter Benefit | 구매자가 실제로 체감하는 차이 | PHASE 03에서 구성·경험·조건을 검증하며 아직 미확정 |
| Consumer-facing | 소비자에게 직접 노출되는 표현 | 내부 가설이나 미확인 사실을 그대로 쓰지 않음 |
| Organic Social | 자연 유입형 SNS 콘텐츠 | 광고비를 직접 지불하지 않고 브랜드가 운영하는 Instagram Feed·Reels·Stories, YouTube Shorts. 친환경·유기농 소재라는 뜻이 아님 |
| Paid Media | 유료 광고 | Meta Ads, WADIZ Ads, Retargeting 등 광고비를 지불해 노출하는 매체 |
| Trust Amplifier | 신뢰 증폭 장치 | 권리 확인된 착용·Creator·UGC가 핵심 전략을 보조하는 역할 |
| Retarget Audience | 기존 고객·팔로워 재접촉층 | 새 Persona가 아니라 CRM 대상 집단 |
| Platform Discovery Audience | 플랫폼에서 새 프로젝트를 발견하는 구매층 | 와디즈 내 제품·패션 프로젝트 탐색층 |
| Working Candidate | 작업용 후보 | 검토 중이며 사용자 승인 전 최종 확정 아님 |
| Final Copy | 최종 소비자 노출 문구 | PHASE 04 이전 작성·확정 금지 |
| Claim | 소비자에게 사실로 말하는 주장 | 근거가 확인된 정보만 사용 |
| USER PROVIDED / EVIDENCE PENDING | 사용자 확인 / 증빙 대조 대기 | 사용자 기억은 기록하되 외부 사실로 확정하지 않음 |
| SOURCE REQUIRED | 근거자료 필요 | 자료가 없으며 추측해서 채우지 않는 상태 |
| NEEDS VERIFICATION | 확인 필요 | 후보 근거는 있으나 현행 SKU·권리·사실 대조가 필요한 상태 |
| Content Clearance | 상업 사용 권리·사실 확인 | Creative Grade와 별개로 실제 사용 전에 수행 |
| CRM | 기존 고객 관계 관리 | 기존 구매자·팔로워에게 다시 안내하고 반응을 확인하는 운영 |
| Retargeting | 재접촉 광고 | 이전 방문·반응 집단에 유료 광고로 다시 도달하는 방식 |
| AOV | 평균 주문금액 | 총 거래액과 유효 주문·참여자 수가 일관될 때만 계산 |
| Funding Amount | 공개 펀딩 금액 | 프로젝트 성과의 한 지표이며 단일 성공 원인을 증명하지 않음 |
| Hero | 가장 먼저 강하게 인지시키는 핵심 시각 또는 구간 | Re-curation이나 Package보다 제품 욕망을 우선 |
| World Building | 세계관 확장 | 제품의 욕망·맥락·의미를 강화하되 구매 증거를 대신하지 않음 |
| Visual Direction | 비주얼 방향 | 실제 제작 전에 화면·자산·편집 원칙을 정하는 기준 |
| Creative Lock | 크리에이티브 방향 잠금 | 재검토 없이 후속 작업에 전달하는 승인된 작업 기준 |
| Shared House System | 공통 브랜드 시스템 | XXX STUDIO의 공통 체계 안에서 Project·Chapter를 구분하는 방식 |
| Distinct Project Layer | 구분된 프로젝트 레이어 | 별도 브랜드가 아니라 공통 체계 안에서 구분되는 Project 표현층 |
| Commerce Utility | 구매정보 모듈 | 가격·옵션·배송·교환처럼 구매 결정에 필요한 정보 영역 |
| Content Gap | 부족 콘텐츠 | 실제 전환·제품 증명에 필요하지만 아직 충족되지 않은 콘텐츠 |
| Worn Record | 실제 착용 기록 | 후기·추천이 아니라 제품이 실제로 착용된 모습을 보여 주는 증거 |

| Gate | 단계 진입 조건 | 후속 단계가 시작되기 전에 충족해야 하는 사실·승인·산출물 |

## STATUS ENUM (상태값 설명)

상태값은 번역하지 않고 아래 의미로 통일한다.

- `NOT STARTED` (미착수): 선행조건 또는 시작 지시 전
- `READY` (착수 준비): 바로 시작 가능
- `IN PROGRESS` (진행 중): 현재 실행 중
- `REVIEW` (검토 중): 산출물 또는 실데이터 검토 중
- `HOLD` (보류): 사용·진행을 잠시 멈추고 추가 확인이 필요한 상태
- `BLOCKED` (차단): 외부 입력이나 결정 없이는 진행 불가
- `APPROVED` (승인): 사용자 승인 Gate를 통과했으나 상위 Phase 전체와는 별도
- `COMPLETE` (완료): 정의된 완료조건까지 모두 충족
