요구사항:

- 본편 15장, 부록 최대 2장
- 16:9, 완전 편집 가능한 PPTX
- 패션 에디토리얼 감도, 강한 여백, 한 슬라이드 한 메시지
- Warm White / Ivory / Deep Charcoal / Black 중심
- DAY는 자연광과 따뜻한 백색, NIGHT는 딥 차콜과 통제된 조명
- 제품이 화면의 주인공이고, 스토리와 패키지가 의미를 확장하게 구성
- 과도한 카드 UI, 둥근 박스, 그라데이션, 템플릿 아이콘 금지
- 발표자가 10~12분 안에 설명할 수 있도록 본문을 짧게 유지
- 각 슬라이드에 30~60초 분량의 발표자 노트 작성

중요:

- 실사, 로고, 제품 사진, 패키지 렌더를 새로 생성하지 마세요.
- 사진이 필요한 위치는 `[PHOTO PLACEHOLDER — ID]`로 비워 두세요.
- 플레이스홀더에는 추천 크롭 비율, 피사체, 배경 톤, 시선 방향을 메모하세요.
- 신규 Set Box는 아직 디자인되지 않았으므로 실제 디자인처럼 만들지 마세요.
- 원가, 마진, 광고 예산, 미확정 가격·리워드·배송일을 외부 슬라이드에 넣지 마세요.
- 저스피스 공식 협업, 해외 인기, 앰배서더, 추천 관계를 주장하지 마세요.
- 현재 실물 124개는 “판매가능재고”가 아니라 “수량 확인 / 판매가능 상태 확인 필요”로 표시하세요.
- CAP 재고는 0이며 주문량 기반 생산 가설입니다.
- 와디즈 정책과 글로벌 기능은 미팅일 기준 확인이 필요한 항목을 명확히 구분하세요.
