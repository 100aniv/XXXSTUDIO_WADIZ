# WADIZ MEETING QUESTION BANK

## 사용법

질문을 모두 읽는 인터뷰가 아니다. 먼저 와디즈의 연락 배경을 듣고, 답변에 따라 다음 질문을 선택한다. 답변은 `확정 / 확인 필요 / 담당자 확인 / 자료 요청` 중 하나로 기록한다.

## P0 — 반드시 확인

### 1. 제안 배경

1. XXX STUDIO를 어디에서 처음 발견했나요?
2. 어떤 제품·콘텐츠·브랜드 요소를 보고 연락하셨나요?
3. 이번 제안의 1차 목적은 프로젝트 오픈, 카테고리 강화, 글로벌, 프로모션, 입점 중 무엇인가요?
4. 와디즈 내부에서 기대하는 프로젝트의 성공 기준은 무엇인가요?

### 2. 프로젝트 적합성

5. 기존 출시 컬렉션을 새로운 세트·패키지로 구성할 때 가장 적합한 유형은 프리오더의 특별구성인가요?
6. DAY/NIGHT 동일 제품군의 조합과 서로 다른 제품의 Scene Set은 각각 특별구성으로 인정될 수 있나요?
7. 신규 Set Box가 특별구성의 근거가 되려면 제품 조합·가격혜택·증빙이 어느 수준까지 필요하나요?
8. 자사몰에서 동일 단품을 유지하면서 와디즈 전용 세트를 운영할 수 있는 정확한 경계는 무엇인가요?

### 3. 가격·리워드

9. 패션 카테고리에서 T-SHIRT, SWEATSHIRT, CAP의 최근 실제 결제 수용 가격대는 어느 정도인가요?
10. 단품→Scene Set→Full Set 구조에서 권장하는 리워드 행 수와 옵션 수는?
11. 세트의 할인과 신규 패키징 중 어떤 요소가 전환에 더 크게 작동하나요?
12. 얼리버드는 어떤 구성에, 몇 개 수준으로 제한하는 것이 적절한가요?
13. 프로젝트 공개 전 가격·할인·정상가 증빙에서 특히 자주 반려되는 부분은 무엇인가요?

### 4. 수수료·정산

14. 현재 계정에 적용되는 서비스 수수료, 결제·정산 수수료, VAT, 정액 비용은 정확히 얼마인가요?
15. 첫 메이커 서비스 수수료 할인 대상인가요?
16. 선택 컨설팅을 사용하지 않아도 되는지, 사용 시 실제 제공 범위와 비용은?
17. 특별구성 프리오더의 선정산 가능 여부·비율·수수료·일정은?
18. 글로벌 결제분은 국내 결제분과 어떤 방식으로 합산·정산되나요?

### 5. 오픈예정·마케팅

19. 패션 프로젝트의 오픈예정 알림 목표를 어느 수준으로 잡아야 하나요?
20. 대표 이미지와 제목을 판단하는 내부 기준 또는 과거 데이터가 있나요?
21. 알림 신청→결제 전환의 카테고리 기준 범위는?
22. 와디즈가 무료로 제공할 수 있는 노출·콘텐츠·CRM 지원은 무엇인가요?
23. 유료 광고 상품의 최신 재고·단가·수수료·추천 조합은?
24. 기획전·홈배너·앱푸시·SNS·글로벌 페이지 노출은 어떤 조건으로 선정되나요?
25. 담당 MD가 프로젝트 기획과 상세페이지에 직접 피드백하는 범위는?

### 6. 글로벌

26. 국내와 글로벌을 하나의 프로젝트에서 동시에 운영할 수 있나요?
27. 현재 의류와 모자 배송이 가능한 국가와 제한 국가는?
28. 자동 번역은 이미지 안의 텍스트와 리워드 정보까지 어디까지 지원하나요?
29. 글로벌 광고 타기팅, 글로벌 메인/기획전 노출, 쿠폰 지원은 현재 어떤 조건인가요?
30. 해외 배송 파트너가 담당하는 수출신고·관부가세·추적·분실·반품 범위는?
31. 해외 CS는 와디즈와 메이커 중 누가 어떤 언어로 담당하나요?
32. 국가별 배송비와 예상 배송기간은 리워드 구조에 어떻게 반영해야 하나요?
33. 글로벌 판매 데이터는 국가·유입·전환·객단가 단위로 제공되나요?

## P1 — 가능하면 확인

34. 메이커가 볼 수 있는 사전/진행/종료 후 데이터의 범위는?
35. 프로젝트 종료 후 앵콜·스토어·후속 생산으로 이어지는 조건은?
36. 배송 지연 가능성이 있는 CAP 포함 세트를 단품과 분리 발송할 때 운영상 주의점은?
37. 의류 사이즈 교환과 해외 반품에서 권장하는 정책은?
38. 목표금액 설정과 수정 가능 범위는?
39. 공개 후 변경이 불가능한 항목을 최종 체크리스트로 받을 수 있나요?
40. 다음 미팅 전 우리가 제공해야 할 자료와 와디즈가 제공할 데이터는 무엇인가요?

## 미팅 종료 전 반드시 고정

- 와디즈 담당자와 내부 의사결정자
- 프로젝트 유형
- 계정 기준 수수료 확인 경로
- 필요한 제출자료
- 글로벌 검토 담당자
- 다음 일정
- 각 항목의 오너와 마감일
