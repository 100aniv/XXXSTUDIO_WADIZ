## CHAPTER 1 — BRAND

### SLIDE 01 — COVER

- 목적: 프로젝트의 위계와 미팅 목적을 한 번에 제시
- 헤드라인: `XXX STUDIO × WADIZ`
- 서브: `REPUBLIC OF KOREA TOUR / CHAPTER 01 — SEOUL : DAY & NIGHT`
- 보조: `OFFLINE MEETING · 2026`
- 비주얼: 넓은 여백, 브랜드 심볼 또는 프로젝트 마크 1개
- 플레이스홀더: `[BRAND MARK — P01]`

### SLIDE 02 — 우리가 어떤 브랜드인가

- 헤드라인: `WE BUILD EXPERIENCES THROUGH FASHION.`
- 핵심 문장: `XXX STUDIO는 패션·디자인·예술 콘텐츠를 하나의 경험과 세계로 연결하는 Experience Brand입니다.`
- 보여줄 것: EXPERIENCE를 중심으로 ANYWHERE / ANYTHING / ANYTIME이 확장되는 구조
- 말할 것: 옷이 결과물이지만, 고객이 만나는 것은 장면·그래픽·물성·이야기가 결합된 경험
- 금지: “옷을 안 파는 브랜드”처럼 제품을 약화하는 표현

### SLIDE 03 — 경험이 제품으로 완성되는 방식

- 헤드라인: `PRODUCT → SCENE → DESIGN → PACKAGE → CONTINUITY`
- 핵심: 제품이 먼저 욕망을 만들고, 장면과 패키지가 제품의 의미를 확장한다.
- 비주얼: 한 방향의 얇은 흐름. 카드 UI 금지.
- 플레이스홀더:
  - `[PRODUCT — P03-A]`
  - `[SCENE — P03-B]`
  - `[PACKAGE — P03-C]`

## CHAPTER 2 — REPUBLIC OF KOREA TOUR

### SLIDE 04 — KOREA TOUR 소개

- 헤드라인: `REPUBLIC OF KOREA TOUR`
- 핵심 문장: `한국의 장면을 패션과 콘텐츠로 기록하고, 도시별 챕터로 확장하는 장기 프로젝트.`
- 위계:
  - XXX STUDIO
  - EXPERIENCE
  - REPUBLIC OF KOREA TOUR
  - CHAPTER 01 — SEOUL
- 비주얼: 브랜드→프로젝트→챕터의 세로 위계

### SLIDE 05 — 왜 KOREA TOUR를 기획했는가

- 헤드라인: `A CITY IS NOT A SOUVENIR. IT IS AN EXPERIENCE.`
- 핵심:
  1. 한국의 익숙한 장면을 관광기념품 문법이 아닌 패션 문법으로 다시 본다.
  2. 장소의 빛·건축·좌표·언어를 제품 그래픽으로 번역한다.
  3. Invitation, Ticket, QR, Postcard는 여행의 물성을 만드는 Experience Device다.
- 비주얼: 장면 → 티켓/초대장 → 제품으로 이어지는 편집
- 플레이스홀더: `[KOREA TOUR INVITATION/TICKET — P05]`

## CHAPTER 4 — PRODUCT & PACKAGE

### SLIDE 10 — 상품 소개

- 헤드라인: `2 SCENES × 3 PRODUCTS`
- 2×3 구조:

| | T-SHIRT | SWEATSHIRT | CAP |
|---|---|---|---|
| DAY | Warm / Ivory | Core apparel | White / embroidered |
| NIGHT | Black | Core apparel | Black / embroidered |

- 제품 역할:
  - T-SHIRT: 가장 낮은 진입 장벽
  - SWEATSHIRT: 컬렉션의 패션 Core
  - CAP: 서울 한글 시그니처가 가장 직접적으로 보이는 제품
- 제품 사실은 `CANONICAL_PRODUCT_FACT_MATRIX.csv` 기준
- 플레이스홀더: 각 셀에 제품 컷 1개. 사람 착용사진 대신 단품/디테일 우선.

### SLIDE 11 — 패키징은 제품 밖의 경험

- 헤드라인: `THE PACKAGE CONTINUES THE JOURNEY.`
- 기존 경험물:
  - Invitation Envelope
  - Ticket / Boarding Pass
  - Postcard / Scene Card
  - Pouch / Sticker / QR
- 와디즈 신규 제안:
  - Scene Set과 Full Set을 위한 신규 Set Box
  - 단품 포장을 무조건 중복하지 않고 FULL LAYER / SUBSTITUTION / HYBRID 비교
  - CAP 형태 보존, 배송 부피, 개봉 경험을 함께 검증
- 중요: 신규 Set Box는 디자인 확정 전. 렌더 생성 금지.
- 플레이스홀더:
  - `[EXISTING PACKAGE PROOF — P11-A]`
  - `[NEW SET BOX PLACEHOLDER — P11-B / DESIGN NOT FINAL]`

## CHAPTER 5 — WHY WADIZ

### SLIDE 12 — 왜 와디즈인가

- 헤드라인: `RE-LAUNCH AS A NEW EXPERIENCE, NOT A CLEARANCE.`
- 핵심:
  1. 기존 컬렉션을 단순 할인 판매하지 않는다.
  2. DAY/NIGHT 전용 세트와 패키징으로 새로운 구매 이유를 만든다.
  3. 오픈예정 알림, 전환, 리워드 선택 데이터를 통해 가격·구성·메시지를 검증한다.
  4. 검증된 반응을 후속 생산과 다음 도시 챕터에 연결한다.
- 와디즈에서의 운영 가설:
  - Apparel: 검증 재고 우선 + 조건부 추가생산
  - CAP: 주문량 기반 선주문 생산
  - 리워드: 단품 → Scene/Pair Set → Premium Full Set

### SLIDE 13 — 국내 검증에서 글로벌 가능성까지

- 헤드라인: `FROM SEOUL TO A GLOBAL AUDIENCE`
- 표현 방식: 목표와 검증 질문으로 제시. 이미 해외에서 성공한 것처럼 말하지 않는다.
- 확인된 와디즈 기능/가능성:
  - 하나의 프로젝트에 국내 배송 리워드를 포함하고 해외 배송 국가를 설정할 수 있음
  - 스토리 번역, 해외 결제, 글로벌 광고, 해외 배송 파트너, CS 지원 안내
  - 글로벌 페이지/기획전 노출 기회는 선정·조건에 따라 달라짐
- 우리가 검증할 것:
  - 패션 카테고리와 의류/모자의 해외 배송 적합성
  - 번역·CS·관부가세·반품·국가별 배송비
  - 실제 지원 가능 국가와 프로모션
  - 국내 프로젝트와 글로벌 동시 운영 시 일정·정산·리워드 구조
- 플레이스홀더: 세계지도 장식 대신 `SEOUL → SELECTED COUNTRIES`의 얇은 타이포/라인
